# Documentation index

Technical reference for accshift. One line per document, naming the question it
answers.

- [platform-descriptors.md](./platform-descriptors.md): how do I add a platform
  without compiling anything, what may a descriptor touch, and what does each
  field mean?
- [cli.md](./cli.md): how do I install and script the `accshift` command, what
  does it print, and what does each exit code mean?
- [analytics.md](./analytics.md): what does the app send, what does it never
  send, and how do I turn it off, export it or delete it?
- [logging.md](./logging.md): what does a log record contain, how do I replay a
  failed attempt from its identifier, and how much disk does the log use?
- [theming.md](./theming.md): what goes in a theme file, what does each token
  control, and what happens to a theme that is incomplete or written for an
  older version of the format?

Elsewhere:

- [../.github/SECURITY.md](../.github/SECURITY.md): what is protected at rest,
  what the PIN lock covers, what is out of the threat model, and how to report
  a vulnerability privately.
- [../.github/CONTRIBUTING.md](../.github/CONTRIBUTING.md): how do I set the
  project up, what must pass before a pull request, how do I propose a
  platform?
- [The wiki](https://github.com/klNuno/accshift/wiki): the full user guide.
  Anything aimed at someone using the app rather than building it lives there,
  not here.

Screenshots and demo clips are in [../.github/assets](../.github/assets), which
is why this directory holds text only.
