# accshift for Stream Deck

A Stream Deck plugin with one action, **Switch account**: put one key per
account, press it and accshift switches to that account.

- Plugin UUID `dev.mtsu.accshift`, action `dev.mtsu.accshift.switch`.
- Built on Elgato's Node SDK (`@elgato/streamdeck`, MIT) and packed with the
  Elgato CLI (`@elgato/cli`, MIT). Both licences allow redistribution; the
  bundled `bin/plugin.js` keeps their notices.
- Needs Stream Deck 7.1 or later (Node.js 24 runtime), Windows 10 or macOS 12.

## How it works

The property inspector asks the plugin for the lists, and the plugin runs the
accshift CLI:

- `accshift platforms --json` fills the platform list,
- `accshift list <platform> --json` fills the account list.

Both need **Allow the accshift CLI** (accshift: Settings > General >
Integrations). When it is off, the inspector says so.

A key press opens `accshift://switch/<platform>/<account id>` (the format of
`parse_deep_link` in `crates/accshift-app/src/lifecycle/deep_link/link.rs`).
The running accshift app handles it: its PIN lock, its deep link setting and
its confirmation still apply. The plugin never runs `accshift switch`.

The key title is the account name. The key image is the account avatar when
the CLI output names a local image file (`avatarPath`, `avatar_path`), else
the platform logo, the same paths as the app's title bar.

### Finding accshift

The CLI is looked up in this order:

1. `ACCSHIFT_CLI`, for development.
2. Windows: next to the `accshift://` handler the app registers
   (`HKCU\Software\Classes\accshift\shell\open\command`), then
   `%LOCALAPPDATA%\Accshift\accshift.exe` (the installer's folder), then the
   `PATH`.
3. macOS: `/Applications/Accshift.app/Contents/MacOS/accshift`, the same in
   `~/Applications`, `/usr/local/bin`, `/opt/homebrew/bin`, then the `PATH`.

When none is there, the key shows an alert and a short "No accshift" title,
the inspector shows how to get accshift, and the plugin log gets
`accshift is not installed: no accshift CLI at <places tried>`.

macOS: the app bundle registers no `accshift://` scheme yet
(`tauri.macos.conf.json`), so a key press there ends in an alert and a log
line until it does.

## Develop

```sh
pnpm install --frozen-lockfile
pnpm test        # unit tests, Node built-ins only
pnpm build       # writes bin/, ui/inspector.js, the locale files and the icon
pnpm package     # build, streamdeck validate, streamdeck pack
```

`pnpm package` writes `dist/dev.mtsu.accshift.streamDeckPlugin`; open it to
install the plugin. To try a local CLI build, start Stream Deck with
`ACCSHIFT_CLI` set to its path.

The repo gate runs the tests too (`node scripts/gates.mjs streamdeck`).

## Files

- `src/link.js`: the switch link.
- `src/cli-output.js`: the `accshift.v1` envelope and each platform's
  account fields.
- `src/cli-locate.js`: where the CLI is.
- `src/accshift.js`: runs the CLI and opens links.
- `src/switch-account.js`: the action, without the SDK.
- `src/plugin.js`: the SDK entry point.
- `src/inspector.js`, `src/inspector-model.js`: the property inspector.
- `src/i18n.js`: every string, in the app's seven languages; Stream Deck's
  `en`, `fr`, `es` and `zh_CN` locale files are generated from it.
- `src/platform-icons.js`: generated by `scripts/sync-icons.mjs` from
  `crates/accshift-egui/src/ui/components/platform_icons.rs`.
